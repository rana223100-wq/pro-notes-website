FREE HOSTING OPTION (GitHub Pages):
1. Sign in/create a GitHub account at https://github.com/
2. Create a NEW PUBLIC repository named: pro-notes-website
3. Upload all files and folders from this package, keeping the folder structure.
4. In repository Settings > Pages, choose "Deploy from a branch", branch "main", folder "/ (root)", then Save.
5. Wait for the published URL shown on the Pages settings screen. It typically looks like:
   https://YOUR-GITHUB-USERNAME.github.io/pro-notes-website/
6. Open the homepage and both policy pages in a private/incognito window to ensure public access.
